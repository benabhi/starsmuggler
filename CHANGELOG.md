# Changelog

All notable changes to Star Smuggler for Android. Versions follow semver: each approved issue is a patch, each closed plan a minor.

## [0.0.1] - 2026-11-03

### Added
- Multi-module Android project (`:app`, `:engine`, `:content`, `:data`) built with the Gradle wrapper and installed over adb (SMUG-2).
- App `com.starsmuggler` named "Star Smuggler", minSdk 26, portrait only, with an empty cream screen (SMUG-2).
